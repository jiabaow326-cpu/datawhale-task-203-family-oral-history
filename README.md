# U57 家庭口述档案整理实操包

本套件用一份完全虚构的带时间码练习转写稿，演示如何把口述素材整理成有来源、能复核、保留不确定性的家庭档案。没有真人、真实访谈或原始录音；素材日期、人物、地点、故事都为虚构。它不能证明任何现实授权，也不能当作真实录音转写。

## 交付内容

- `tutorial/家庭口述档案整理实操教程.md`：五步教程，每一步都给出原因、具体动作、材料、复制给 AI 的提示词和完成标志，并将上一步成果作为下一步输入。
- `materials/`：可打开的 `.srt`、`.txt`、`.csv`、旧版本、重复副本和错误 AI 草稿；埋入版本冲突、时间码冲突、未经确认的旁人信息和授权缺项。
- `reference/参考档案与陷阱核验.md`：样例档案、陷阱逐项依据、需保留的不确定点。
- `reference/核验记录模板.md`：可填的审阅记录。
- `templates/家庭口述档案模板.md` 与 `templates/AI提示词模板.md`：可复用模板。
- `references.md`：个人信息保护法官方文本来源与使用边界。

## 安全提示

真实录音含可识别的声音、姓名、经历或第三人信息。处理前须确认说话人对转写、AI 处理、保存、分享/公开分别同意的范围；不确定就停在本地、先征求本人意见。不要把未经允许的音频、逐字稿、姓名、联系方式或家庭隐私上传给 AI。AI 草稿不能代替本人确认；拒绝或撤回后按约定停止使用，并按适用流程处置副本。

## 文件说明

`材料来源说明.txt` 明确这只是仿写文字素材，时间码是教学示例，不对应音频波形。练习时可以让 AI 整理这份文字；不能把它说成真实转写结果。要演练真实录音，换成已获同意且脱敏的副本，并让本人复核。
