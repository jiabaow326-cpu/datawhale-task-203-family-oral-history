# AI 提示词模板：口述素材的安全整理

不要把未授权录音、姓名、联系方式、家庭秘密或第三人内容贴入 AI。先确认使用工具、内容和目的均在本人同意范围内；拿不准就只用虚构示例。

## 转写整理

```text
请只整理我获准处理的转写材料，保留时间码、说话人代称、原话和不确定措辞。听不清写[听不清]，冲突写[待核实]。不得补写日期、地点、亲属关系、人物现况，不得把口述改成已证实史实。对每处建议修改，单独列出原文、建议和理由，不要覆盖原文。
[粘贴已授权、脱敏的片段]
```

## 版本核验

```text
请只用我提供的版本对照表，列出一致、冲突、重复、缺项和无法推断。每项附文件名、时间码或行号。不同版本不自动以新旧决定史实；不得猜第三人身份或授权。输出授权范围尚缺项时，明确写“暂停分享/公开”。
[粘贴已脱敏的版本内容]
```

## 主题索引

```text
请按主题组织口述索引。每个条目保留原话、说话人代称和回查时间码；区分本人记忆、材料记载、核实完成与待核实，不润色成客观事实。没有提供的数据写“未提供”。请单独列出需本人复核和第三人需删除/确认的内容。
[粘贴已授权的处理稿与核验记录]
```

## 分享前复核

```text
请逐项检查这份档案是否超过本人确认的处理范围：转写、AI 处理、家庭内保存/分享、公开发布分别列状态。标出第三人、住址、联系方式、未成年人和未核实事实。不要判定或生成同意，不要代签或发布。任一范围未确认时建议保留为草稿并暂停分享。
[粘贴授权范围摘要和已脱敏档案]
```

本人/组织的真实授权、版本采纳和最终分享决定均由本人/有权人员完成。
